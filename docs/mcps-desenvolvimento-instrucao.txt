# MCPs ativos no desenvolvimento

Lista de Model Context Protocol servers configurados para uso com o
Claude Code no ImobPro. Instalados em scope `user` (~/.claude.json),
então valem para todos os projetos do Arthur, não só este.

---

## Instalados

### context7
Documentacao atualizada de bibliotecas, frameworks, SDKs e CLIs.
Resolve nomes ambiguos ("Next.js" vs "nextjs") e retorna snippets
versionados. Usado automaticamente quando aparece qualquer pergunta
sobre lib/framework — ver regras globais em ~/.claude/rules/context7.md.

### playwright
Automacao de browser. Permite ao agente abrir o painel, preencher
formularios, clicar e tirar screenshots. Util para validar telas sem
roteiro manual (ex.: rodar o checklist do Sprint 9.4 sozinho).

Reinstalar/atualizar:
  claude mcp add playwright --scope user -- npx @playwright/mcp@latest

### chrome-devtools
Inspeciona Chrome em tempo real: console, network, DOM, performance.
Util quando algo quebra no browser e o erro nao chega no terminal
(ex.: "fetch failed" que pegamos no inicio da sessao).

Reinstalar/atualizar:
  claude mcp add chrome-devtools --scope user -- npx chrome-devtools-mcp@latest

---

## Considerados e descartados

- **FireCrawl** — analise de concorrentes / docs externas. Nao instalado
  por enquanto. Se virar necessario (ex.: comparar pricing do Kommo,
  raspar manual da Z-API), adicionar com:
    claude mcp add firecrawl --scope user -- npx firecrawl-mcp@latest
  (requer FIRECRAWL_API_KEY na env)

- **Glift, Perplexity** — nao agregam ao stack atual; Context7 cobre
  pesquisa de docs.

---

## Verificar status

  claude mcp list

Mostra cada server e se esta `✓ Connected` ou com erro.
